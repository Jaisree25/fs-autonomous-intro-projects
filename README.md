# Project 1 — Tensor Workshop

* Explored what tensors are and how they represent data in machine learning.

* Practiced creating and manipulating vectors and matrices using PyTorch.

* Performed addition, subtraction, and multiplication between tensors.

* Learned how to reshape, squeeze, and unsqueeze tensors to prepare them for neural networks.

* Gained a clear understanding of how data moves and transforms inside AI models.

# Project 2 — Neural Network (MNIST + Digit Addition)

* Built a simple convolutional neural network (CNN) to recognize handwritten digits using the MNIST dataset.

* Extended the model to take two handwritten digits and predict their sum, combining recognition and arithmetic.

* Learned how to structure, train, and evaluate a neural network from scratch.

# Project 3 — Glove vs. No-Glove Classification

* Created a CNN that classifies whether a hand is wearing a glove or not.

* Processed images using YOLO-style bounding boxes to crop and extract hand regions.

* Used data augmentation (rotations, flips, brightness shifts) to balance the dataset.

* Trained the model to achieve around 95% test accuracy.

* Visualized performance with confusion matrices and evaluation metrics.
